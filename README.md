# Human Resource Management Analysis- EXCEL

This project demonstrates end-to-end Excel analysis, from cleaning HR data to building PivotTables and a clear dashboard.

### Tools: PivotTables, charts, Excel formulas (IF, TRIM, PROPER, SORT, FILTER), and formatting.

**Impact:** Helps HR and operations teams track workforce trends and support planning and reporting.
